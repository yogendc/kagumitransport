# KAGUMI Transport — Frontend

Aplikasi administrasi sewa & pengiriman kendaraan (frontend statis untuk GitHub Pages).

- Backend: Google Apps Script REST API (`Kode.gs`, tidak disimpan di repository ini)
- Alamat API diatur di `js/config.js` (`GAS_URL` berakhiran `/exec`)
- Panduan lengkap: [PANDUAN-INSTALASI.md](PANDUAN-INSTALASI.md)

```
index.html        halaman aplikasi (SPA)
css/style.css     tampilan
js/config.js      alamat API  ← satu-satunya berkas yang perlu diubah
js/app.js         logika aplikasi
```
